# Yimaprof

Plateforme de préparation aux examens pour les élèves du Cameroun (sections francophone et anglophone).

**Site** : https://yimaprof.com

## Stack

- React 18 + Vite + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (auth, base de données, storage, edge functions)

## Développement local

```sh
npm install
npm run dev
```

## Build de production

```sh
npm run build
```
